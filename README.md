# Spending Log



## About

An Android app (Kotlin) that tracks daily spending against a daily

budget for one week, to help monitor cost of living in 2026.



## Features

- Splash screen (3 seconds)

- View all spending (date, budget, spent, comment)

- Calculate remaining budget per day and for the week

- Exit button



## How it works

Uses 4 parallel arrays (dates, budgets, spent, comments), loops to

display and calculate, and Activities for screen navigation.



## How to run

1. Clone the repo

2. Open in Android Studio

3. Run on an emulator or phone
