# Spending Log



## About

An Android app (Kotlin) that tracks daily spending against a daily

budget for one week, to help monitor the rising cost of living in 2026.



## Features

- Splash screen that opens the main screen after 3 seconds

- View all spending (date, budget, spent, comment)

- Calculate remaining budget for each day and for the week

- Exit button



## How it works

- 4 parallel arrays (dates, budgets, spent, comments), each with 7 items

- Loops to display and calculate the data

- 4 screens linked with Intents (screen navigation)

- Error handling with try/catch and friendly messages



## How to run

1. Clone this repository

2. Open it in Android Studio

3. Press Run on an emulator or phone
